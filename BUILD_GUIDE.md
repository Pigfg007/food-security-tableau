# Build guide v2: editorial redesign (AN6004 Tableau project)

**Files**
- `FoodSecurity_Dashboard.twbx`: packaged workbook.
- `FoodSecurity_Dashboard.twb` with `Data/food_security_2017_2023.csv`: the same workbook unpackaged, using the relative path `Data/`.

## Data
`food_security_2017_2023.csv` is the annual file LEFT JOINED on ISO3 to the country summary file: 976 rows, 142 countries.
- Summary fields repeat on every year row, so **filter Year = 2023** on any sheet that uses them.
- Two columns were added from the existing data: `Diet_Change_Rank_Worst` and `Diet_Change_Rank_Best`, the rank of `Healthy_Diet_Change_pp` among 2023 rows (1 = largest change). They drive the top/bottom-10 cut.
- In Tableau, set ISO3 > Geographic Role > Country/Region (ISO3166-1 alpha-3).

## Calculated fields
```
Flag Count        = IIF([Both_Elevated_And_Both_Worsened]='Yes',1,0)
Improved Count    = IIF([Healthy_Diet_Change_pp] <= -1,1,0)
Worsened Count    = IIF([Healthy_Diet_Change_pp] >= 1,1,0)
Diet 2017 Median  = MEDIAN(IF [Year]=2017 THEN [Healthy_Diet_Unaffordable_Pct] END)
Diet 2023 Median  = MEDIAN(IF [Year]=2023 THEN [Healthy_Diet_Unaffordable_Pct] END)
Highlight         = IIF([Both_Elevated_And_Both_Worsened]='Yes','High on both & worse on both','Other countries')
Top 10 Worsened   = [Diet_Change_Rank_Worst] <= 10
Top 10 Improved   = [Diet_Change_Rank_Best] <= 10
Africa Accent     = IIF([Region]='Africa','Africa','Other')
```
Alternative to the rank columns: the table calc `RANK(SUM([Healthy_Diet_Change_pp]),'desc') <= 10` used as a filter.

- Title: "In the typical country, 1 in 4 people can't afford a healthy diet. In Africa it's 6 in 10."

**KPI sheets** (Text mark; Year=2023; Label = big number + line break + caption):

|---|---|---|

| D1 KPI Diet | MEDIAN(Healthy_Diet_Unaffordable_Pct) = 24.5% | accent |
| D1 KPI PoU | MEDIAN(Undernourishment_Pct) = 5.2% | ink |
| D1 KPI Flag | SUM(Flag Count) = 9 | accent |

**Hero Map** (x30 y250 w800 h580):
- Filled map of ISO3, Year=2023.
- Colour AVG(Healthy_Diet_Unaffordable_Pct) on the custom 4-step scale, fixed 0–100.
- Map > Background Layers: Washout 0, base style Light, all layers off except Land. Country borders `#F6F3EE`.
- Annotation text under the map: South Sudan 94% (highest); Haiti 54% undernourished (highest).

**Annotated Scatter** (x860 y250 w500 h560):
- Columns AVG(Healthy_Diet_Unaffordable_Pct), Rows AVG(Undernourishment_Pct), Detail Country, Colour Highlight (accent / `#8A94A6`), Circle at size 1.2.
- Analytics > Trend Line (linear, exclude colour); r = 0.76.
- Reference lines (constant, `#C9C3B8` dotted): X = 55.2 labelled "Top quartile 55.2%", Y = 13.1 labelled "Top quartile 13.1%".
- Optional: shade the top-right quadrant with a reference band.
- Right-click > Annotate > Mark for Haiti, Syria, Madagascar, Nigeria. Use an Area annotation for "Europe clusters at the 2.5% reporting floor".
- Filter `PoU_At_2p5_Reporting_Floor`, shown as a single dropdown under the chart: selecting only "No" gives n=80, r≈0.65.

**Filters and actions:**
- Region dropdown, top right, applied to All Using This Data Source.
- Action: Map select filters Scatter.
- Action: Scatter hover highlights ISO3.

## Dashboard 2: "Who is falling behind"
**Header:** "Healthy diets got more affordable in 63 countries, but 38 slipped back."

**KPI sheets:**

| Sheet | Value | Colour | Note |
|---|---|---|---|
| D2 KPI Median | `<Diet 2017 Median>% → <Diet 2023 Median>%` = 28.6% → 24.5% | ink | no Year filter |
| D2 KPI Improved | SUM(Improved Count) = 63 | `#2A9D8F` | Year=2023 |
| D2 KPI Worsened | SUM(Worsened Count) = 38 | accent | Year=2023 |
| D2 KPI Max | MAX(Healthy_Diet_Change_pp) = +30.9 pp | accent | caption "Syria, 24.7% → 55.6%" |

**Dumbbell Worsened / Dumbbell Improved** (x30 w640, stacked):
- Rows Country, sorted by SUM(Healthy_Diet_Change_pp).
- Columns Measure Values (Healthy_Diet_2017_Pct, Healthy_Diet_2023_Pct) on a shared axis.
- Circle marks; Colour Measure Names (2017 `#C9C3B8`, 2023 accent or `#2A9D8F`); Label = change in pp.
- Filter Top 10 Worsened / Top 10 Improved = True, and Year = 2023.
- **Connecting line (manual step):** duplicate the axis as a dual axis, set mark Line, Path = Measure Names, size 3, 45% opacity, then synchronise the axes.

**Regional Small Multiples** (x700 y250 w660 h400):
- Columns Region / Year; Rows MEDIAN(Healthy_Diet_Unaffordable_Pct), axis hidden.
- Area mark, 12% opacity fill; Colour Africa Accent (Africa accent, others ink).
- Label only the first and last points (Label > Marks to label: Line ends).

**Worst Cell List** (x700 y655): Text table of Country, filtered to Both_Elevated_And_Both_Worsened = Yes and Year = 2023. These are the 9 countries.

**Footer:** sources and caveats (pp vs %, the 2.5% floor, thresholds are not UN definitions, association only).
