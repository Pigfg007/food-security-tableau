# Food Security Tableau Dashboard


## Contents
- `BUILD_GUIDE.md` — Design system, layout, and rebuild instructions
- `data/` — Cleaned country and regional food security datasets (2017–2023)
- `_build/` — Python scripts that generate the Tableau workbook (`.twb`)

## Key files
- `food_security_2017_2023_CLEAN.csv` — Main analysis dataset
- `FoodSecurity_Country_Burden_Progress_2017_2023.csv`
- `FoodSecurity_Regional_Tableau_2017_2023.csv`

## How to use
1. Review `BUILD_GUIDE.md` for the visual design system and sheet specifications.
2. Use the scripts in `_build/` to regenerate the Tableau workbook if needed.
3. Open the resulting `.twb` / `.twbx` in Tableau Desktop.

Focus on food security burden and progress across countries and regions.
